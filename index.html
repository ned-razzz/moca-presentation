04 / 주요 기술

음성 인식: 정확도 개선

① 문제 메뉴·수량어 오인식
② 원인 경량 ASR 한계 · 65% / WER 30%
③ 해결 · ASR Context
주입 컨텍스트
// 메뉴·수량어 bias
const ASR_CONTEXT = '매장 주문. 핫도그, 콜라, 커피. '
  + '자주 쓰는 말: 하나, 한 개, 한 잔, 둘, 두 개, 두 잔, 개, 잔.';

// 음성마다 context 전송
fd.append('context', ASR_CONTEXT);   // → POST /asr/transcribe
65% → 95% WER 30%→5%
개선 방안: 응답 지연시간 단축
① 스트리밍 STT 전환 비스트리밍 STT → 스트리밍 모델 · 발화 중 추론·합성
발화 중 STT·LLM → 스트리밍 TTS → 음성 응답
② 응답 음성 사전 생성 응답이 정형화 → 음성파일 사전 준비로 합성 시간 단축
정형 응답 → 음성 사전 생성 → 즉시 재생
목표 응답 지연 ≈ 0.5초 사람 대화 평균 수준
