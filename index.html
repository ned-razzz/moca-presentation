이동성, 자동화, 안전성, 관리성을 모두 만족해야 한다.

행동트리(cafe_funnel) 순차 흐름

  • [1] IdleScan 그룹 탐지 → [2] Approach 그룹 접근 → [3] IceBreak 자기소개 → [4] Minigame 미니게임 → [5] Offer 메뉴 홍보
  • 탐지·접근·추종은 시각 인식 기반 자율주행(YOLOv8 · DBSCAN · BoT-SORT · PD 제어)

  • 감정 분석(geva → rapport)은 전 구간 병렬 상시, 분노 감지 시 즉시 중단(abort→idle)

※ 고객 영구식별(얼굴 ReID)·분노 재권유금지(blacklist)는 Phase 2 후속. 오인식 윤리·개인정보(생체) 정책상 의도적 분리. 현재는 분노 감지 시 세션 단위 중단(abort→idle)으로 안전 동작.

  • 물체 상태에 따라 goal pose를 갱신하고 MoveIt Planning과 Cartesian Path를 조합
  • Gazebo에서 검증한 제조 동작을 실물 로봇으로 전이해 재현성을 확인

개선 목표

  • 점주와 로봇이 같은 조리 공간을 공유하며 식재료 보충, 조립, 배치를 분담
  • safety zone 안에서 사람이 감지되면 즉시 정지하고 소리로 감지 상태를 알림
  • 사람이 제조 중간 단계를 대신 수행해도 현재 상태를 반영해 다음 단계부터 재개
  • 점주는 예외 판단과 재료 준비를 맡고, 로봇은 반복 제조 동작을 안정적으로 수행
