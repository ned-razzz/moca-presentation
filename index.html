03 / 기획

주제 선정 이유

왜 이동형 로봇 케이터링 서비스인가?

  • 행사장, 팝업스토어, 테마 공간마다 필요한 매장 형태가 다름
  • 기존 방식은 인력 운영과 인프라 구축 비용 부담이 큼
  • 로봇과 사람이 협업하면 최소 인력으로 운영 가능
  • 메뉴와 공간 변화에 유연하게 대응하는 서비스가 필요함

04 / 기획

주제 선정 이유

프로젝트 개요

MOCA는 점주 1명과 로봇이 협업하여 주문, 제조, 서빙, 모객까지 수행하는 이동형 로봇 케이터링 플랫폼이다.

  • 제조 로봇 뚜비: 주문 메뉴 제조
  • 서빙 로봇 도비: 픽업, 테이블 서빙, 모객
  • 관리자 시스템: 주문·로봇·매장 상태 통합 관리
  • 맞춤형 매장 맵: 행사장 환경에 맞게 구성

05 / 기획

사용자 요구사항

맞춤형 매장 구성 다양한 행사장에 맞게 맵과 서비스 환경을 구성
자동 제조·서빙 주문 후 뚜비와 도비가 유기적으로 작업 수행
안전·인터랙션 사람과 함께 움직이는 로봇의 안전성과 친밀감 확보
통합 관리 점주 1명이 전체 주문, 로봇, 매장 상태를 관리
이동성, 자동화, 안전성, 관리성을 모두 만족해야 한다.

13 / 주요 기능

매장 준비

서비스 공간 지도 생성

  • 행사장 도면과 현장 배치를 기준으로 서비스 맵을 생성
  • 테이블, 픽업존, 카운터, 로봇 대기 위치를 운영 지점으로 등록
  • 각 지점의 좌표와 이름을 주문, 제조, 서빙 시스템이 공통으로 참조
  • 현장별 구조 변화에 맞춰 맵과 동선을 빠르게 재구성

14 / 주요 기능

주문: 자연어 기반 주문·결제 흐름

대표 주문 방식

  • 메뉴 선택 GUI와 자연어 음성 입력을 함께 제공
  • QWEN3-ASR로 사용자 발화를 텍스트화하고 Audio LLM으로 주문 의도 파악
  • 메뉴 확인 후 카드 결제와 앱 Pay 결제 흐름으로 연결

15 / 주요 기능

제조: 비전 기반 조작과 시뮬레이션 전이

제조 흐름

  • 주문 확인 후 레시피에 따라 핫도그와 음료 제조 태스크 수행
  • Depth 카메라로 물체 위치를 획득하고 PCA로 주축을 파악해 파지 진입 방향 결정
  • MoveIt Planning과 Cartesian Path를 조합해 케이스 집기, 빵·소시지 배치, 픽업존 배치 실행
  • Gazebo 월드 검증 후 실물 로봇과의 간극을 보정해 전이

16 / 주요 기능

서빙: 픽업·운반·제공을 연결하는 자율주행

서빙 흐름

  • 주문 확인 후 픽업존에서 상품을 수령하고 고객 테이블까지 운반
  • 샌드위치, 음료, 스낵 등 상품 유형별 픽업·제공 동작 분리
  • ACT Policy를 채택해 하드웨어 리소스와 실시간 제어 안정성을 우선 확보
  • 위치·각도 다변화 데이터와 밝기 변화 증강으로 실제 환경 변화 대응

17 / 주요 기능

모객: 감정 인식 기반 고객 인터랙션

도비 모객 구조

  • 점주가 모드 제어 웹 인터페이스로 모객 모드를 수동 실행
  • 사람 탐지 후 접근, 아이스브레이크, 미니게임, 메뉴 제안, 카운터 안내 순서로 진행
  • doby_controller, scout_reactor, omx_reactor가 두뇌·눈·손 역할을 분담
  • MediaPipe 얼굴 특징과 Valence·Arousal 좌표로 호응도와 중단 조건 판단
  • 물리 안전, 운영 정지, 사회적 후퇴를 분리한 3계층 안전 구조 적용

17_1 / 주요 기능

모객: 잠재 고객 탐지·접근·추종 자율주행

추종 동작 흐름

  • 매장 인근 잠재 고객 무리를 탐지하고 인원이 가장 많은 그룹을 선정해 접근
  • 접근 단계부터 추적이 계속 동작하며, 호객 성공 후 가장 가까운 대상을 추종
  • 사람 감지(YOLOv8) → 그룹 클러스터링(DBSCAN) → 다중 추적(BoT-SORT) → 접근·추종 제어(PD·P+EMA)
  • 시각 인식 결과를 cmd_vel로 변환, twist_mux로 주행 명령을 우선순위 통합

※ 고객 영구식별(얼굴 ReID)·분노 재권유금지(blacklist)는 Phase 2 후속. 오인식 윤리·개인정보(생체) 정책상 의도적 분리. 현재는 분노 감지 시 세션 단위 중단(abort→idle)으로 안전 동작.

17_2 / 주요 기능

모객: 탐지 → 접근 → 추종 시연

① 군중 탐지·그룹 클러스터링 (YOLOv8 + DBSCAN)

② 최대 인원 그룹 선정·접근 (PD 제어)

③ 근접 대상 추종 (P 제어 + EMA)

17_3 / 주요 기능

모객: 추종 안정화 트러블슈팅

Before — 지그재그 진동

After — 안정적 추종

회전 게인이 높고 화면 속 대상 위치(bbox) 떨림이 그대로 전달돼 진동 발생 → 회전 게인 인하 + EMA 필터로 떨림 완화 + 회전 후 전진(align_gate)으로 동시 활성 구간 제거
